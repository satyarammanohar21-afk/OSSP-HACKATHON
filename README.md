# Virtual-to-Physical Address Translation Simulator

## 📌 Project Overview

The **Virtual-to-Physical Address Translation Simulator** is an Operating Systems and System Programming (OSSP) project that demonstrates how virtual addresses are translated into physical addresses using **page tables** and the **Translation Lookaside Buffer (TLB)**.

The simulator helps students understand memory management by showing the address translation process step by step, including page number calculation, offset calculation, TLB hits, TLB misses, page-table lookups, and physical address generation.

## 🎯 Objectives

- Understand virtual and physical addresses.
- Demonstrate page-based memory management.
- Simulate page-table mapping between virtual pages and physical frames.
- Understand TLB hits and TLB misses.
- Calculate physical addresses using page numbers, frame numbers, and offsets.
- Provide a simple educational tool for learning operating-system concepts.

## 🧠 Concepts Used

### 1. Virtual Address
A virtual address is generated by a program when it accesses memory.

### 2. Page Table
A page table stores the mapping between virtual page numbers and physical frame numbers.

### 3. Translation Lookaside Buffer (TLB)
The TLB is a small, fast cache that stores recently used address translations to improve performance.

### 4. Page Number and Offset
A virtual address is divided into two parts:
- **Page Number:** Identifies the virtual page.
- **Offset:** Identifies the location within that page.

## ⚙️ Working Principle

1. Enter a virtual address.
2. Calculate the virtual page number and offset.
3. Search for the page mapping in the TLB.
4. If the mapping is found, report a **TLB Hit**.
5. If the mapping is not found, report a **TLB Miss** and look up the page table.
6. Obtain the physical frame number from a valid page-table entry.
7. Calculate the physical address.
8. Display the translation result.

## 🧮 Address Translation Formula

**Page Number**

`Page Number = Virtual Address // Page Size`

**Offset**

`Offset = Virtual Address % Page Size`

**Physical Address**

`Physical Address = (Frame Number × Page Size) + Offset`

### Example

Assume:
- Virtual address = 2500
- Page size = 1024 bytes
- Physical frame number = 5

Calculations:

- Page Number = `2500 // 1024 = 2`
- Offset = `2500 % 1024 = 452`
- Physical Address = `(5 × 1024) + 452 = 5572`

Therefore, the physical address is **5572**.
